# PANEL-V2: Micro-actions, Split polish, telemetry sparklines, diff bars and static HTML board

Elaborates `docs/spec.md` §2.2 (owner, 2026-11-18).

## Scope

1. **Panel micro-actions: Go-to-tab, inline QA reply and safe stop (`01`).** On a selected HUD job (Home, Split Home or Inspector), `g` focuses its herdr tab (`herdr tab focus <TAB>` from `SESSION.txt`). On an expanded open-question slab/card, `d` answers with the question's recorded default (when present) and `1`–`4` select the numbered option, writing `qa/qN.answer.md` atomically (`wx`) just like `hud_respond` and appending an owner-action notice so MCP `changes` / `hud watch` inform the main session. Pressing `X` on an active HUD job prompts a one-line confirmation bar (`Enter`/`y` to stop via `pi-role-reap`, `Esc`/`n` to cancel).
2. **Split layout V2: working cues, adjustable ratio, focus auto-compact and scrollbar (`02`).** Show compact keyword/progress cues on non-selected working rows in Split Home's top list when columns allow. Support `=` / `+` and `-` (plus mouse drag on the rule divider) to adjust the list/preview split ratio, persisted in `MonitorState` across reloads; auto-compact the top list to 3 rows while keyboard focus is inside `preview` (`Esc` restores). Paint a zero-extra-column scrollbar thumb (`┃` over `│` / ascii `|`) on the rightmost cell of scrollable previews when content exceeds viewport height.
3. **Global live `/` filter (`03`).** Pressing `/` on Home, Project Progress or Project Tickets opens a compact inline filter bar (`MonitorState.filterText`, reusing the decoder's `text` input). Filters cards/lanes, ledger slices or tickets live by case-insensitive substring across id, title, package, role and state (`failed`, `try`, `working`, `asking`). `Enter` keeps the filter active and returns navigation keys to the filtered list; `Esc` clears or exits the filter.
4. **Worker activity sparklines, progress milestones and sonic subtrees (`04`).** Sample 10 one-minute activity buckets per active worker from session/report/progress mtime & size deltas, rendering a compact sparkline (`▁▂▃▄▅▆▇█`, ascii `..::##`) plus latest `hud-progress` text in Inspector and expanded cards. Render `sonic` child jobs (`parentJobId`) as compact tree-indented rows (`├─ ⚡ sonic · <title>  <age> <mark>`) directly beneath their parent card in both Classic and Split previews.
5. **Bounded safe Git `--numstat` diff bars (`05`).** Using `src/utils/git-safety.ts` (read-only, no repo filters/hooks/fetch, 5 s gate), collect `--numstat` (top 12 files, `+added -deleted` and proportional 5-cell bar `███░░`) for: (a) To-try slices in Split/Classic Progress previews (from the slice's commit range), (b) Working tree page preview, and (c) Inspector for jobs with a recorded `worktree` or `BASE` commit. `o` / `Enter` on a diff file row opens the file in `$EDITOR` tab.
6. **Control plane quota, spend and dispatch health radar (`06`).** Add a compact `Health & Quota` band on the Control plane (and its Split preview): surface latest observed Claude/Codex quota watermarks from HUD state snapshots, today's pi spend/tokens from pi session summaries, and today's HUD job dispatch tally per role (succeeded / failed / quiet-escalated, average runtime) computed from `$HUD_HOME/jobs`.
7. **On-demand static HTML review board (`07`).** Add `hud board [--html] [--out FILE] [--open]` and panel key `w` (writes `$HUD_HOME/display/board-<project>.html` and opens via `wslview` / `xdg-open` when `--open` or `w` is used, with safe fallback message). Generates a self-contained single-file HTML document (zero external URLs, scripts optional/inline only, light+dark CSS matching HUD themes) showcasing project progress, all To-try slices with model briefs, acceptance steps, linked tickets, commit `--numstat` bars, active jobs and latest milestone reviews.
