### 1. Minor, follow-up — read only the session header during migration

**Location:** `packages/hud-mcp/bin/hud-watch.mjs:115`.

`readFileSync(source, 'utf8').split('\n', 1)` loads and decodes the complete transcript to obtain one header. A large legacy transcript therefore incurs whole-file allocation/I/O; a destination collision can repeat that work on subsequent watcher scans even though no move can proceed.

**Smallest improvement:** read a bounded first line and retain the job if that header cannot be read/parsed within the bound. This is a legacy cleanup path rather than the panel tick, and I established no normal-use stall, so this is a follow-up, not a cost-gate failure or release blocker.
