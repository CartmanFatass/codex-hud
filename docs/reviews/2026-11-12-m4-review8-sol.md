The orchestrator explicitly confirmed that retaining these owner-facing controls is required.

### 2. The machine-readable-state example invokes a command the installer does not install

**Severity: minor; required normal-use documentation correction.** `docs/reference.md:374–378`, `docs/reference.zh.md:295–300` — both references tell the owner to run bare `codex-hud --json`, but the current installer installs only `hud` and `hud-mcp`.

**Smallest fix:** use `hud codex --json | jq ...` in both references and `hud codex brief --dry-run` in both README examples. Alternatively, explicitly use the checkout-relative `bin/codex-hud` path. No installer compatibility alias is needed.
