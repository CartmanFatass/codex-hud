3. §16 五个关注点

① 握手：四条路径尚未全部闭环。（概§6.6.3）

fork：未闭环。 一次性只阻止第二次兑换，fork 抢先兑换仍可占位。claim 须绑定 run/source/启动实例及会话代次，并有独立启动回执或可信会话证据；相同绑定重复 whoami 应幂等成功。
resume：部分闭环。 新 run 正确，但凭据应锚定本轮续跑消息及调用 ID，不能查整个会话“首条消息”；明确旧凭据撤销和新绑定替换。
同 pane 换会话：部分闭环。 procStart 能区分换进程，同进程换 session 仍需使 caller 旧绑定失效；generation 必须进入授权判断。
daemon 代启：无法核实。 prompt 传入 claim 不等于识别当前会话。A3 要验证 MCP 与会话的基数关系、每次调用的可信来源；不能隔离则不支持，修改§14的过早保证。

“父／子”还须变成工具校验：report 只能由该 run 的绑定子提交，resume/cancel 校验所有者。

② 事务：现在不足以兑现全部承诺。 caller_id 随 MCP 重启改变，会绕开旧幂等记录；应使用持久逻辑所有者＋请求键。意图与运行占有须同事务提交，只有取得执行权者启动；对账写成“证据→允许迁移”表。工B4“启动中断→failed”错误：仅证实未执行才 failed，其余 uncertain。取消也须确认退出后才终结。（概§6.6.2–5）

③ hud-run：可保留，先验证可见模式。 “Herdr 检测不受影响”无法核实。A8 须覆盖函数包装、前台进程组、输入、Ctrl-C、尺寸变化、关 pane、父退出；TTY 直通与日志捕获不能含糊。更轻方案：headless 保留 supervisor；visible 沿用原启动路径，加最小退出回执和 sidecar，对缺失回执保留 uncertain，不凭进程消失补退出码。（概§6.6.4）

④ 工作包与角色：纵向切片合理。 ORD 可写跑探针，CORE 对协议结论负责；FE 消费已定观测接口。切分和顺序修正见第4节。

⑤ 三个月内最可能返工： 调用者与会话身份、恢复互斥、采集一致性和历史关系投影，集中见第6节。

4. 工程计划书专项
缺包： 明确五维状态归并器／真值表、统一模型材料入口与“新来源默认不外发”的实现及负向测试；A2 只有契约，不能代替实现。（概§6.8、11；工B）
合拆： A1 内部分批交付但共同审定；B3 拆托管核心与可见终端集成。D2 的最小 checkpoint／摘要一致提交、旧持有者失效前移，与 B12 一起交付。
顺序： A3/A8 结论进入 A1/A2 定稿，再进 A4；统一表、图、§10。A8 依赖 A3 却要求并开，A4 不能绕过 A2；B11 依赖 B10 却宣称并行。全部 B 包受 A9 门禁，B14 显式依赖 B4/B5。B1“三 harness 加载”与 C1“pi 加载”统一排期。
规模： B12 的接管一致性不能按普通半天任务处理；B3/C4 探针后重估，具体工时无法核实。D5 的 S 只能代表工具开发，里程碑仍须计入至少两周观察。
验收： 尚是验收目录。每份 brief 补输入、命令、状态断言、超时和证据路径；A4 fixture 不能证明真实进程恢复。B14 按能力矩阵逐格验证，补 tmux 首次可见启动及 headless resume；未测格不得标支持。

Hermes＋脚本可用，但证据不足以独立判定通过。 usage JSON 证明调用发生，截图证明瞬间画面；身份、输入落点、退出及重复运行须由脚本核验账本／进程／回执。绕过共享输入队列的路径应标“未覆盖”，不能仅注明后算通过；NEEDS_HUMAN 无人完成恢复时，只能验收阻塞呈现和锁保持。（工§6）

5. 委派工作流专项

风险分层路由合理，以下规则须修改：

“每变更恰好一次评审”与“两轮后升级”矛盾。改为一个主审负责初审及修复复核，批准绑定最终差异版本；自带 reviewer 与外派 reviewer 明确责任归属。
只有跨契约、不变量、范围的分叉才升级 ARCH；普通可逆实现选择交 CORE，仅暂停受影响工作。
升级先区分代码缺陷与环境／旧基线故障，接手有效成果，不默认整包重做。
并行任务目录不是代码隔离；由 ORCH 建 worktree 或规定文件所有权，集成后再验收。清理先保存报告、确认运行结束，再关 surface。（流“升级规则／约定”）
6. 新增返工风险，按严重度排序
账本写者矛盾。 HUD 只读却要回填身份，实施必然分叉；回填归 MCP／reconciler，HUD 只投影。采集租约另定观测存储或明确写者。（概§6.2、6.6.3、6.7、6.11；工B5/B9/B12）
三类租约不能共用过期即放行。 session/browser 失联不证明任务停止，可能重复执行；持久运行槽继续阻断 uncertain，确认结束后释放。collect 可按代次接管，并拒绝旧持有者迟写。（概§6.6.2、6.6.7、6.11）
换任务后的会话归属未定。 predecessor 是新会话谱系，还是旧会话转交？这影响 spawn 参数和树的唯一父边。先选定；若转交，区分当前所有权与历史关系。（概§6.5–7）
7. 开工前必须补齐
P0： 首批 brief 明列上述身份、幂等、恢复问题为 A9 阻断项；删除“恰好一次”等未证实保证，纠正 B4 验收。
P1： 统一权威依赖表，明确身份回填、状态归并、材料授权与采集一致性的责任包。
P1： 改定主审复核、并行修改隔离和证据验收规则。

补入这些执行约束即可开工阶段 A；探针结果和完整契约属于 A 的产出，不应再被前置为开工条件。
