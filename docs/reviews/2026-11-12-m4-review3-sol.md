## Findings — simplicity and quality

### 1. Major — Retention permanently deletes legacy pi history stored inside a job

**Location:** `packages/hud-mcp/bin/hud-watch.mjs:146–150`, especially the unconditional recursive removal at `:149`.

**Defect and owner-visible scenario:** A job created by an older, still-running HUD MCP server has real `<job>/sessions/*.jsonl` files rather than links. Once its terminal timestamp is over one day old, the next watcher scan recursively deletes those files with the job. The owner loses the session history and cannot resume it. Removing `--session-dir` from new launches does not protect existing files or launches from unrestarted servers; `docs/handoff/STATE.md:20–23` explicitly records that remaining path. The external dispatch extension's self-link guard deliberately leaves those real files in place.

**Fresh reproduction:** Through `tmp/env.sh`, I created two synthetic closed jobs settled 25 hours ago: one with a real `sessions/legacy.jsonl`, the other with a link to history in the temporary HOME's default pi session directory. I ran the **unmodified real `hud-watch.mjs`**, without a reaper stub or clock interception. It exited 0, logged deletion of both jobs, and produced:

```json
{"watcherExit":0,"stderr":"","legacyJob":false,"legacyHistory":false,"linkedJob":false,"defaultHistory":true}
```

The default history's bytes survived unchanged; the legacy history was gone. The new retention tests do not seed real session history, so their green result does not cover this upgrade case.

**Smallest fix:** Before recursive deletion, inspect `sessions/` without following links and retain the job if it contains real history; an unreadable session directory must not authorize deletion. Alternatively, move history safely to pi storage and verify preservation before removing the job. Keep link-only cleanup unchanged.

This violates spec §4's irreversible-data-loss boundary. On clarification, the orchestrator confirmed that manual migration/restart is **not** an accepted substitute for protecting legacy history in code.
