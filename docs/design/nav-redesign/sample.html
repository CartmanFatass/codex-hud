Panel navigation: Project and Execution, element to element

Design sample for D-2026-11-26-04; nothing is built. Every frame is a terminal grid: one glyph per cell, CJK two cells, every row exactly the panel width (the generator throws otherwise), mocha colours, Nerd Font glyphs embedded as outlines. Rows are composed from the panel’s own helpers; Execution cards, runs and the delegation tree come from the shipped renderer over synthetic jobs. Rules, row shapes and open questions are in README.md.
