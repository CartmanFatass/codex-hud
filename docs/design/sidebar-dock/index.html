Least urgent projects shrink to one line, then +2 counts the rest with their most urgent shape.

  • One block per project with an active run, most urgent first: ?, ×, ◐. Top to bottom is run order; side by side is parallel; review and accept end the graph. Solid line: travelled. Dashed: ahead.
  • Too tall, in this order: landed steps fold, then queued tickets, then whole projects shrink to one line, then +N. +N always means “N not drawn”. The rail never scrolls.
  • Clicks: a step or a project name opens Execution there. A folded +N step line opens Execution on that run; the +N projects line opens Home, which lists them.
  • Rule not drawn here: a project with a second active run shows its most urgent graph, then a +1 run line.
