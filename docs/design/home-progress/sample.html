Home, Progress & Tickets: Design Sample (首页、进度与工单重设计样本)

9 frames × 2 languages (18 terminal grids), every row verified at build time to be exact 40 terminal cells (CJK wide glyphs = 2 cells), painted with the shipped terminal (dark) and latte (light) board palettes from src/render/palette.ts. Synthetic project harbor-api only; zero JavaScript, zero network fetches. Companion rationale & spec audit: docs/design/home-progress/README.md.

2 · Classic Home & Slice Granularity (经典布局首页与「切片」粒度)

The same rollup rules keep Classic Home under 36 rows (2a) and prevent Detail = slice from turning sequential plans into a wall of blocked / 受阻 rows (2b).

3 · Project Progress & Tickets Pages (项目进度页与工单页联动)

Project › Progress groups active feature streams under 0.4.0 (3a); Project › Tickets derives Working and To try / Done live from jobs, commits and STATE.md, resolves cross-feature blockers, and folds normal dependency queues separately from real stalls (3b).
