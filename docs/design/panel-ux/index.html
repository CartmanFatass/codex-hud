PANEL-UX-01

Panel to-try rows, counts and tabs

These panes are the panel's real renderer output at 40 columns in Chinese, with synthetic data and the Mocha theme. A to-try slice reads as a short brief; one number says how many are left to try; the digit keys leave the tabs.

Tabs have no number keys

  • Switch with ← →, Tab or a click on the tab.
  • A ?N badge counts what waits on you in that tab. It is a count and never a key hint.
  • The Changes page that 3 used to open is now f.

One number for what is left to try

  • The Waiting row says 2 · 5 待试用 and the Progress row says 0.1.3 · 5 待试用. Both count every to-try slice in the ledger, whatever its milestone.
  • The Progress row has a single form: the milestone, then the counts that are not zero, dropping the last ones when the row is narrow.
  • The meter reads 0/4 已验收, so its n/m says it counts accepted slices of the milestone. Tickets read 3/14 完成.
  • A slice with a brief shows its first sentence right beside its ID. A slice without one keeps the ledger text, wrapped whole under the row.

The Progress page reads as briefs

  • Each to-try row is one line: ID, then the brief's first sentence, cut with an ellipsis when it does not fit.
  • Rows with no brief keep the state word, so the list stays aligned.
  • The preview below the list shows the whole brief, the numbered steps and the ledger line, folded.

The preview keeps the original text one key away

  • Brief first, then 试用步骤 as numbered steps. The ledger text sits under ▸ 台账原文.
  • Enter on that line unfolds it; the same key folds it again. Nothing is rewritten: the ledger keeps its own words.
  • With no brief, or with the model off, the preview shows the whole original text wrapped, never broken inside a word or a path.

Other keys that changed

1–4, d
On an expanded question, answer its options directly; d takes the default. No r first.
= + -
Resize the Split list. The divider can no longer be dragged, and the panel no longer asks the terminal for drag events. Clicks and the wheel stay.
← → Tab
Switch tab, as before, plus a click.
