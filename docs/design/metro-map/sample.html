Execution workflow as a metro map: three variants

Design sample for D-2026-11-26-09 (docs/design/tab-roles/README.md §3a); nothing is built. Every frame is a terminal cell grid at 62 or 40 columns, composed by the layout script in this file (the same function for every variant, width, language and mode), in the panel's default theme. Box, half-block and braille cells are drawn as cell-filling shapes, as terminals with built-in glyphs draw them. Synthetic data. Glyph tables, tokens, rules and the recommendation: README.md.
