Home cards: Today and Schedule

Design sample, nothing built. Every frame is a terminal grid: one glyph per cell, CJK two cells, every row exactly the panel width (checked when this page was generated), mocha colours, Nerd Font icons as the panel draws them. The Home above the cards is the settled portfolio design (home-portfolio, its Proposed frames composed from the same helpers); the tab row and footer are the shipped renderer's. Today's numbers are what the shipped collectJobStats returns over synthetic job and land records. Contents, data sources, storage, fold order and questions are in README.md.

Short panel: the cards fold first

The same Home at 40 columns on shorter panels. The cards use only the rows the full-tier project list leaves; each step down is one fold: full, compact (landings and context rows go), one row each, due items only, gone. Only after that do project blocks shrink (the portfolio design's tiers). Frames show the smallest panel height that keeps each level.

Empty day

A zero that was read is shown (暂无); Schedule is absent when it has no item and no quiet project. A failed read of the land or job records would show neither (unknown is absent, never a fabricated zero).

How a due item becomes visible without becoming a request

One item through its life, excerpts of the tab row and the Schedule card (40 columns). Nothing is ever written to Waiting, to STATE or to the owner count: the item changes its own row, its place in the card, the card's fold floor and a separate tab badge. A request exists only if someone records one.
