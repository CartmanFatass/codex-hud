# E4 headless close: approved decision

Status: approved, 2026-11-06.

Cancel stops the current run and preserves possible resume. Close explicitly ends
the delegation relationship, without deleting its underlying session, reports, code
or history. Only the authenticated parent may close a confirmed, current-owned
headless target pinned by expectedRun. Independent existing termination evidence
is required before closed. Uncertainty remains pending.

Visible/local-manager close, reopening, real-time send/ask, paused HUD chat UI and
capability expansion are excluded. The exact acceptance, immutable replay, recovery
and budget rules are in docs/cloud/E4-HEADLESS-CLOSE.md. This resolves the former
blanket-close deferral; no additional owner decision is required inside this scope.
