### Reuse path from segment 1

1. Once per tick: `proj = projectDelegation(vm)`, with one `ProjectionCache` per view-model source.
2. Once per second, or on a selection or fold change: `plan = planRows(proj, { nowMs, collapsed, showHistory,
   sortByCreation })`. It returns the tree drawing, the folds and the `⊕N` row; `plan.coarse` is set when more than
   30 rows are active.
3. Per frame, visible rows only: `renderRow(plan.rows[i], { proj, width, nowMs, selectedKey, coarse, say: panelSay })`.

## Goal

1. Panel tree (compact) and rich cards for the delegation view, at panel widths 32–56 (Codex ≥ 41), matching the
   samples of scenarios (a)–(h) on synthetic view models.
2. The micro card for the selected node, accordion folding of rich cards (§3.5), and the §4.2 summary row.
3. Native rows: the name comes from `native.title` and the kind icon from `native.kind`, with the existing fallbacks
   when either is null. The ASCII fallback and CJK widths are exact.
4. `delegation` absent or null: panel output byte-identical to today.
