# 0.2.0

MCP orchestration and Panel V2: the HUD runs the fixed steps of delegation itself, and the panel shows only what needs you.

## Fixed flows run inside the HUD

`hud_land` lands a finished worktree job as one flow: gate in a fresh worktree, fast-forward, build, push, clean up, and update the ticket.
Failures go back to the job's implementer, at most two repairs, then the flow hands back to the main session once.
Lands queued together form a train that shares one integration checkout and one gate run.
A scouted dispatch gives the worker a sonic fact dossier first.
A closed job that receives `hud_send` becomes a repair job that references the old brief and report.
Create and send keys are derived when omitted, so a repeated call does not start a second job.
Named leases (`hud_lease`) serialise shared resources a brief names and are released when the holder ends.
Optional project checks run after a worker's report and before it settles; their outcome travels with the result.

## Workers report through the HUD

Workers on pi, CLI harnesses and Antigravity share one worker MCP.
`hud_report` writes the report, an optional one-line summary, the file list and the done receipt in one call.
The worker instructions no longer carry job protocol; commands, paths and valid values come from the MCP.

## The main session reads less

`hud_read` defaults to a digest (summary, paths, questions, checks, progress); `mode: "full"` pages the report.
MCP results to every client are compact `key: value` text; set `HUD_MCP_JSON=1` for JSON.
Mutating tools accept batches (`hud_create({ jobs })`, ticket updates), and per-item errors come back in input order.
Clients that declare MCP tasks (Claude Code) get one task per worker turn whose completion carries state, summary and check outcome.

## A Claude Code mod

The `claude` extension now installs a Claude Code mod.
While it runs `hud watch --mod`, it owns wake for the session in place of MCP tasks, so HUD jobs leave `/tasks` and batch create works.
The first wake lists fresh unread reports; older ones fold into one line.
A band above the prompt shows only what needs you (at most two rows) with Open and Accept all buttons.
Slash commands answer without a model turn: `/hud`, `/jobs`, `/answer`, `/try`, `/retry`, `/stop` and `/land`; the same actions are available as `hud act`.
Convention rules that are mechanical run as hooks in the main session and are skipped if they fail.

## Roles and placement

`imp` has a placement mode: `fixed` (one preset), `even` (rotate chosen presets by job count over the last day, to balance subscriptions) or `auto` (routing).
`general` is the flexible seat: any model, thinking or preset, and any role's instructions for one job (`instructions: "<role>"`).
Sonic is a headless one-shot lookup role with automatic thinking, including `none`.
`pro` and `flow` are optional roles.
Antigravity joins Claude Code, Codex and pi as a supported main session, with its own status line and event delivery.
Grok is switched off and its `imp` presets are removed.

## Panel V2

Control is a main tab beside Home and Project: roles at their limit, roles with nowhere to run, role files that do not load, usage and files.
Home shows progress from tickets and land records, a failed job leaves once superseded, and the top line counts workers per role since the panel opened.
Icons default to a Nerd Font set, with `unicode` and `text` as fallbacks.
Mouse works everywhere: the first click selects, the second opens.
Trying shrinks to Accept all plus the items the main session flags for you.
A native Linux x64 status line ships in the archive; the TypeScript one is the fallback.

## Tickets

`hud_tickets` lists ready tickets and adds or updates local tickets under `.scratch/`, and `hud tickets sync` mirrors GitHub parent and sub-issues.
Tickets are the only slice ledger; `docs/handoff/STATE.md` keeps milestone, now, waiting and next.
A ticket counts as landed only through a commit that changes more than `.scratch/`.

## New commands

- `hud doctor` checks the installation without changing it; `hud doctor <jobId>` prints one job's disk facts.
- `hud --version` prints version, build commit and build time.
- `hud stats` and `hud day` report job usage, outcomes and landings from a monthly facts archive kept before job deletion.
- `hud act answer|try|retry|stop` runs owner actions from a shell.

## Removed

- Project's Timeline and Board layouts; Project keeps Inbox.
- The per-slice try flow (y/n marks, try briefs and steps, try detail, the `m` land intent).
- Six bar themes; bars keep `line` and `p10k`.
- The job `kind` label and Home's Recommended ranking.
- The backup-skills list in Help; see `docs/optional-skills.md`.
- CodeGraph in every harness and in worker instructions.

## Install

The archive ships its vendored `node_modules` with the lockfile stamp, so `./install` works offline and does not need `sha256sum`.
