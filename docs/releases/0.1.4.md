# 0.1.4

Roles now describe the work (`instructions`) separately from where it runs (`run`:
an ordered list of places across `pi`, `cli`, and `bro`). Old single-place role
files continue to load as `run[0]`, and `"harness": "jev"` loads as `"bro"`.

`hud_roster` reports each role's ordered `run` places, its first available place
(`runs_on`), and active exhausted marks. `hud_create` dispatches on `runs_on`
or an explicit `on` harness/provider override using defaults from `harnesses.json`
and `$HUD_HOME/harnesses.json`, with `model`, `thinking`, `kind`, and `pi` switches
applied on top.

When a job fails due to a quota or rate limit, HUD records a 1-hour mark in
`$HUD_HOME/exhausted.json` and names the next available place in `exit_reason`
instead of retrying automatically. CLI execution reads
`packages/hud-mcp/instructions/<instructions>.md` (`implementer.md` and read-only
`reviewer.md`), returning `unsupported_harness` when missing. `oracle` merges
ChatGPT Pro, Gemini, and AI Studio Argon as ordered `bro` places, `flow` accepts
`kind` (`image` or `video`), and the legacy per-backend role files (`grok-imp`,
`agy-imp`, `claude-imp`, `codex-imp`, `argon`, `gemini`, `flow-video`) are
removed.
