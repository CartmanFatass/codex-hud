# 0.1.1

Roles may run on an interactive coding CLI herdr supports, not only pi. A role file
names the harness (`cli`) and the agent (`grok`, `agy`, `claude` or `codex`). Shipped
roles: `grok-imp`, `agy-imp`, `claude-imp`, `codex-imp`. Register another under
`$HUD_HOME/roles/`. The HUD passes only the model flag, the effort flag, that CLI's
permission-bypass flag and the role's `args`. It does not change harness behaviour
or session places, and it declines a directory-trust dialog instead of trusting it.
CLI jobs use the same report, idle grace, continuation, questions, stop and reap
path as pi jobs. `hud trust <dir>` adds a directory to grok, agy and claude trust
lists after a backup; an untrusted launch names that command. Codex is skipped.
