# Optional skills

MyHUD ships these Matt Pocock skills but does not install them. Ask the main session to read the linked skill when you need it.

- [wayfinder](../integrations/skills-optional/wayfinder/SKILL.md) — Map a large, foggy effort as decision tickets and settle them one at a time.
- [grill-with-docs](../integrations/skills-optional/grill-with-docs/SKILL.md) — Interview the owner on a fuzzy idea, keeping a glossary and decision records.
- [to-spec](../integrations/skills-optional/to-spec/SKILL.md) — Turn the conversation into a spec with user stories and testing seams.
- [hud-build](../integrations/skills-optional/hud-build/SKILL.md) — Build a spec's tickets as a task graph, one imp per ready ticket.
- [tdd](../integrations/skills-optional/tdd/SKILL.md) — Red-green-refactor at the seams the spec agreed.
- [diagnosing-bugs](../integrations/skills-optional/diagnosing-bugs/SKILL.md) — Build a feedback loop first, then reproduce, hypothesise and fix.
- [triage](../integrations/skills-optional/triage/SKILL.md) — Sort issues others filed: reproduce, dedupe and turn them into agent-ready briefs.
- [prototype](../integrations/skills-optional/prototype/SKILL.md) — Write throwaway code to answer one design question about logic or UI.
- [retro](../integrations/skills-optional/retro/SKILL.md) — After a session, improve the agents' environment, not the code.
- [teach](../integrations/skills-optional/teach/SKILL.md) — Set up a separate learning workspace with lessons, practice and a record.
- [wizard](../integrations/skills-optional/wizard/SKILL.md) — Write an interactive Bash wizard for steps only a human can do.
- [pr](../integrations/skills-optional/pr/SKILL.md) — Write a PR body with before-and-after evidence and mark decisions that are hard to reverse.
- [codebase-design](../integrations/skills-optional/codebase-design/SKILL.md) — Use a shared vocabulary for deep modules, small interfaces and where seams go.
- [improve-codebase-architecture](../integrations/skills-optional/improve-codebase-architecture/SKILL.md) — Survey the codebase for modules worth deepening, with a comparison report.
- [to-questionnaire](../integrations/skills-optional/to-questionnaire/SKILL.md) — Turn a question you cannot answer into a questionnaire for an expert.
- [wait-what](../integrations/skills-optional/wait-what/SKILL.md) — Ask for the last reply to be explained another way.
- [writing-for-agents](../integrations/skills-optional/writing-for-agents/SKILL.md) — Write skills, AGENTS.md and briefs that agents can follow.
