# Implementer (`imp`) Worker Context, Cost & Latency Load Study (2026-11-22)

Companion study to `docs/llm/orch-load-2026-11-22.md`. Aggregate analysis of `pi`-backed `imp` worker sessions in this repository across a ~24h active window (`63` MyHUD `pi` `imp` jobs + `69` child `sonic` jobs from `~/.hud/jobs`, plus `3` `pi` and `18` `agy` jobs in a secondary workspace) cross-checked against 5-day historical MyHUD worktree sessions (`2026-11-18` to `2026-11-22`, `135` `pi` `imp` sessions). Contains aggregates and categories only.

## 1. Executive Summary

- **Baseline 24h load (`66` parsed `pi` `imp` sessions: `63` MyHUD + `3` secondary workspace):**
  - **`3,225` assistant turns** (`48.9` mean turns/job), **`310.88M` prompt tokens** (`9.74M` uncached input = `3.1%`, `301.14M` `cacheRead` = `96.9%`), **`1.45M` output tokens** (`22.0k`/job).
  - **Direct cost: `$80.56`** (`$25.55` uncached input [`31.7%`] + `$37.45` `cacheRead` [`46.5%`] + `$17.56` output [`21.8%`]) plus **`69` child `sonic` jobs** (`154.22M` prompt tokens, **`$3.95`**) = **`$84.51` combined** (`~$83/24h` for MyHUD alone — already **~2× the prompt tokens and ~1.7× the spend** of the pre-optimization Opus orchestrator baseline of `150.5M` tok/d and `$48.60/d`).
  - **Wall time:** `14.32h` total (`781s` = `13.0m` mean/job): **`72.5%` LLM inference** (`10.39h`) and **`27.7%` tool execution** (`3.97h`).
  - **Cost shock under the new `gpt-6.2-astra` default (`from 2026-11-22 11:43Z`):** At `$8 / $0.40 / $40` per MTok (**4.0×** `gpt-6.2-sol`), the first `6` `astra` `imp` jobs average **`$3.65–$3.91/job`** (`$3.50` median; heavy slices `HOME-PROGRESS-02` `$7.78`, `HOME-PROGRESS-01` `$5.23`, `ASYNC-WATCH-05` two runs `$7.71`). At `45` jobs/day unoptimized, `imp` spend projects to **`~$165–$175/day`**.
- **Structural contrast with the Claude Code orchestrator:**
  - **Fixed overhead is NOT the problem in `pi` `imp`:** Turn-0 prompt is only **`5,853` tokens median** (`6.0%` of prompt token-turns vs `30.4%` in Claude Code `orch`), because `pi-role` already launches with `-ne -ns`. Compaction occurred only once across 63 jobs (`MONITOR-STATE-03` at `254k`), and `cacheWarming: "idle"` admitted `0` requests (`$0.00`).
  - **`94.0%` of load is dynamic context × turn count × model unit price.** `read` tool outputs alone account for **`74.0%` (`715.27M` char-turns)** of all dynamic context residency. Because uncached input costs **20× `cacheRead`**, early unnecessary reads hurt twice: `20×` on arrival plus `1×` across all ~45 remaining turns.
- **Top five structural wastes (`63` MyHUD `pi` `imp` jobs):**
  1. **Unrequested repo/archived doc reads (`~22%` of all prompt tokens, `~66M` tok-turns, `~$10.7`):** `pi` auto-loads the obsolete 2026-11-03 root `AGENTS.md` (`5.2 KB`), which tells every agent to read `STATE.md`, `docs/archive/cloud/dots.md`, `docs/archive/cloud/README.md`, `cloud-development/*`, and `ARCHITECTURE.md`; `CLAUDE.md` and `implementer.md` reinforce this, pulling `STATE.md` (`55/63` jobs), `spec.md` (`48/63`), `ARCHITECTURE.md` (`54/63`), `delegation.md` (`42/63`), and archived `cloud/*` docs (`42/63`) into Turns 4–9.
  2. **Broken CodeGraph MCP in worktrees (`98.6%` failure rate):** `53/63` (`84.1%`) jobs called `mcp__codegraph__codegraph_explore` and **`73/74` calls failed** (no `.codegraph/` inside `../MyHUD-wt/<WP>` + 12 schema validation errors); `bash` `codegraph` CLI also failed `12/18` (`66.7%`).
  3. **`git` inspection & raw diff dumps (`15.8%` of turns, `$11.70` / `14.8%` of spend, `47.4%` of all `bash` output):** `435` `git_read` calls (`6.9`/job, up to `24`/job) with single `git diff`/`git show` outputs up to `51 KB`.
  4. **`hud_sonic` polling (`92` poll-only turns, `9.63M` prompt tokens, `$2.07`, `1,027s` LLM wait) + `74.9%` file-read duplication:** `114/133` (`85.7%`) `hud_sonic` wait calls used `timeout_s: 0` polling (encouraged by `"0 checks once"` in `worker-tools.mjs`), and `161/215` source files read by child `sonic` were also read directly by the parent `imp`.
  5. **Turn-1 `read(brief.md)` (`63/63` jobs = `100%`), single-tool sequentialism (`79.0%` of tool turns call only 1 tool; `107` streaks of 2–7 serial read/grep turns), and unrequested/repeated full `npm run test:mjs` (`50` runs across `35/63` jobs, `3,022s`, of which `16` were unrequested and `15` were same-job repeats) plus `for ... sleep ... tail` bash polling loops.**
- **Combined savings:** Engineering & prompt fixes alone (Ranks 1, 3–7, keeping the same model) cut prompt tokens by **`~35%–45%`**, per-job cost by **`~30%–40%`**, and wall time by **`~25%–35%`**. Adding tiered model routing (Rank 2: `sol-fast` default for ~80% routine slices, `astra` for ~20% high-complexity slices) cuts daily `imp` spend by **`~70%–78%` vs an all-`astra` baseline** (from `~$165–$175/d` down to **`~$38–$45/d`** at 45 jobs/day).

### 2.3 Cost Composition & Transient Upstream Cache Drops

- Across all three models, **uncached input accounts for `30%–36%` of spend** despite being only `3.1%` of tokens, **`cacheRead` is `45%–50%`**, and **output (including reasoning) is `19%–24%`**.
- **Mid-session cache drops (`10` events across `8/63` jobs = `0.53M` re-billed tokens, `+$2.59`):** Forensic inspection of the two largest drops (`HOME-PROGRESS-02` T39: `126k → cr=0k` after `11.9s`, `+$0.963`; `ASYNC-WATCH-05` T36: `96k → cr=0k` after `12.2s`, `+$0.731`) confirms **zero prefix mutation and immediate recovery to `126k`/`96k` on the very next turn** — i.e., transient upstream replica cache misses. On `astra` (`$8/MTok`), a single transient miss at `126k` context costs nearly as much as an entire `sol-fast` job, making lean context residency doubly valuable.

### 3.4 Key Tool & Workflow Anomalies

- **CodeGraph MCP (`98.6%` failed):** `53/63` jobs called `mcp__codegraph__codegraph_explore` (`74` calls: `12` validation errors + `61` `"isn't indexed with codegraph (no .codegraph/ directory found)"` in `../MyHUD-wt/<WP>`; only `1` call succeeded, in the main checkout). `bash` `codegraph` CLI also failed `12/18` (`66.7%`). Root cause: `tmp/wt-new.sh` symlinks `node_modules` only, yet `pi-role` still spawns `pi-mcp-adapter` + `codegraph serve --mcp`.
- **`git_read` bloat (`435` calls = `35.4%` of all `bash`, `1.55M` chars = `47.4%` of `bash` output):** `git status` (`159`), `git diff` (`158`), `git grep` (`37`), `git log` (`28`), `git show` (`25`), `git ls-files` (`18`). Single `git diff`/`git show` outputs hit `51 KB` (`BUILD-DEDUP-01`, `SPEC-DOCS-03`, `MONITOR-STATE-01`), dumping just-written patches back into context.
- **`hud_sonic` polling & overlap (`59/63` jobs used `sonic`):** Asynchronous overlap is healthy (`13.0` median turns between start and first wait, `0` immediate blocks), **but `114/133` (`85.7%`) wait calls were `timeout_s: 0` polls**, creating **`92` poll-only turns (`9.63M` prompt tokens, `$2.07`, `1,027s` LLM time)**. Meanwhile **`161/215` (`74.9%`)** of files read by child `sonic` were also read directly by `imp`; the `69` child `sonic` sessions averaged `42.4` turns / `2.23M` prompt tokens / `$0.057` (`7 KB` median report).
- **Single-tool sequentialism & giant reads:** **`79.0%` (`2,424 / 3,070`)** of tool turns invoke only 1 tool (`1.96` calls/turn mean), with `107` streaks of 2–7 serial `read`/`grep` turns (`269` turns), `13.6` mean turns before first edit (`p90 = 19`), `33` adjacent single-file sequential `edit` turns, and `286` single `read` outputs `>=15 KB`.
- **Unrequested/repeated full `npm run test:mjs` & bash polling loops:** `50` full `test:mjs` runs across `35/63` jobs (`3,022s` = `50.4m`), including **`16` unrequested runs (`13` jobs)** and **`15` repeat runs within the same job**. Multiple jobs also ran background test scripts polled via `for/while ... sleep ... tail` (`90–164s` per bash call), echoing legacy instructions in `integrations/pi/roles/implementer.md:7`.
