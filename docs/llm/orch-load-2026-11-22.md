# Orchestrator Context & Token Load Study (2026-11-22)

Aggregate analysis of Claude Code (`claude-opus-5-5`, high effort) orchestrator sessions driving HUD workers in this repository, cross-checked against `toktrack` and six session transcripts (`S1`–`S6`). Contains aggregates and categories only.

## 1. Executive Summary

- **Baseline daily load:** Across active MyHUD development days (2026-11-18 to 2026-11-22), the Opus orchestrator averages **`~686` root turns/day and `~150.5M` root prompt tokens/day** (`~$46.60/day` root re-estimated API cost + `~$2.00/day` native subagents ≈ **`$48.60/day`**; machine-wide Opus across all projects averages `927` requests/day, `181.8M` prompt tokens/day, `$60.57/day`).
- **99.2% of prompt tokens are cache reads (`205,948` mean prompt tokens/turn in `S1`):** Cost is governed by the product of **context width** (what stays resident across 197–235-turn compaction segments) and **turn count** (every extra API round-trip re-reads ~206k cached tokens).
- **Where context goes (`S1`, `781` turns, `160.85M` prompt token-turns, `100.0%` API-reconciled):**
  1. **Tool results (`35.95%` / `57.82M`):** Dominated by `Bash` (`25.67%` — searches, file reads, background-task polls, landing scripts), `codegraph_explore` (`3.90%` from just 7 calls — Ranks #1–#7 largest single tool outputs), and `hud_read` full worker reports (`3.82%`).
  2. **Fixed overhead (`30.40%` / `48.90M`):** Turn 0 starts at **`57,650` tokens** (`68.7k–73.4k` post-compaction). Unused schemas and listings account for ~60% of this floor: **`Artifact` alone is `58,216` chars (`9.69%` of the entire session)** despite `docs/delegation.md` ruling out Artifacts; global `skill_listing` (49 skills, `25.0 KB` = `4.13%`), unused built-in schemas (`Workflow`, `ScheduleWakeup`, `ReportFindings` = `2.12%`), native subagent schemas (`1.87%`), and unused global MCP servers/deferred tools (`~2.3%`) make up the rest. **All 9 `hud_*` MCP schemas combined are only `7,387` chars (`0.90%` of session).**
  3. **Orchestrator own generation (`23.70%` / `38.13M`):** `tool_use` inputs (`15.08%`, led by `Bash` inline scripts/commands at `9.93%` and inline `hud_create` briefs at `2.50%`), server-retained adaptive `thinking` (`5.96%`), and visible `text` (`2.67%`).
  4. **Task notifications & system reminders/hooks (`7.81%` / `12.56M`):** HUD MCP task wakes (`1.88%`), `UserPromptSubmit` codegraph prompt-hook (`1.38%` from 6 prompts), background `Bash` / subagent / `Monitor` wakes (`2.75%`), and file/turn reminders (`1.80%`).
  5. **Compaction summaries (`1.79%`) & owner prompts (`0.35%`).**
- **Where turns go (`S1`, `781` turns):** `30.9%` (`241` turns = `43.1M` prompt tokens) main-session `Bash` searching/reading/git-inspecting; `14.3%` (`112` turns = `23.3M` prompt tokens) `sleep && tail` polling of background test suites; `14.1%` (`110` turns) text replies; `12.6%` (`99` turns = `22.3M` prompt tokens) mechanical worktree creation (`tmp/wt-new.sh`), cherry-pick/cleanup, and Python-heredoc edits to `docs/handoff/STATE.md`; and `17.3%` (`135` turns) HUD MCP calls.
- **Headline savings:** Config + workflow changes alone (Ranks 1–3, **zero product code**) cut **~48% of daily orchestrator tokens (~72M prompt tokens/day, ~$23/day)**. Adding four small HUD improvements (Ranks 4–6 & 8) cuts **~68% (~102M prompt tokens/day, ~$33/day)** without weakening test-before-land or worker neutrality.

### 3.2 Under-Used Zero-Copy & Automation Mechanics (`S1`: 60 `hud_create` Dispatches)

- `context_files` / `from_jobs`: **`0 / 60`** (proposal docs and prior reports read into main context and pasted inline).

- `report_meta`: **`0 / 47`** `hud_read` calls in `S1` carried `report_meta` because `S1` started before `REPORT-SUMMARY-02/03` landed and had not reconnected `/mcp`.
