# Orchestrator Context & Token Load Study (2026-11-22)

Aggregate analysis of Claude Code (`claude-opus-5-5`, high effort) orchestrator sessions driving HUD workers in this repository, cross-checked against `toktrack` and six session transcripts (`S1`–`S6`), incorporating the 2026-11-22 owner addendum on delegation to `sonic`/`imp`, MCP ↔ panel interaction, and MCP tool batching/payloads. Contains aggregates and categories only.

## 1. Executive Summary

- **Baseline daily load:** Across active MyHUD development days (2026-11-18 to 2026-11-22), the Opus orchestrator averages **`~686` root turns/day and `~150.5M` root prompt tokens/day** (`~$46.60/day` root re-estimated API cost + `~$2.00/day` native subagents ≈ **`$48.60/day`**; machine-wide Opus across all projects averages `927` requests/day, `181.8M` prompt tokens/day, `$60.57/day`). One Opus turn at `206k` mean context costs **`~$0.062`**, whereas a complete 10–20-step `sonic` worker job in a fresh context costs **`$0.03–$0.05` total**.
- **Where context residency goes (`S1`, `781` turns, `160.85M` prompt token-turns, `100.0%` API-reconciled):**
  1. **Tool results (`35.95%` / `57.82M`):** `Bash` (`25.67%` — searches, reads, background-test polls, landing scripts), `codegraph_explore` (`3.90%` from 7 calls — Ranks #1–#7 largest tool outputs), and `hud_read` full worker reports (`3.82%`).
  2. **Fixed overhead (`30.40%` / `48.90M`):** Turn 0 starts at **`57,650` tokens** (`68.7k–73.4k` post-compaction). **`Artifact` alone is `58,216` chars (`9.69%` of session)** despite `docs/delegation.md` ruling out Artifacts; global `skill_listing` (49 skills = `4.13%`), unused built-in schemas (`Workflow`, `ScheduleWakeup`, `ReportFindings` = `2.12%`), native subagent schemas (`1.87%`), and unused global MCP servers/deferred tools (`~2.3%`) dominate. **All 9 `hud_*` MCP schemas combined are only `7,387` chars (`0.90%`).**
  3. **Orchestrator own generation (`23.70%` / `38.13M`):** `tool_use` inputs (`15.08%`, led by `Bash` scripts/commands at `9.93%` and inline `hud_create` briefs at `2.50%`), server-retained `thinking` (`5.96%`), and visible `text` (`2.67%`).
  4. **Task notifications & reminders/hooks (`7.81%` / `12.56M`), compaction summaries (`1.79%`), and owner prompts (`0.35%`).**
- **How much of `orch`'s load is outsourceable chores (`S1`–`S6`):** **`45.47%` of total session residency (`65.3%` of all dynamic context) and `72.6%` of all turns (`567 / 781` turns = `113.55M` prompt tokens)** are mechanical chores: codebase/doc/diff searching (`31.8%` of turns), worktree/cherry-pick/test-suite/polling loops (`25.4%` of turns), `STATE.md`/ticket upkeep (`5.8%` of turns), full report reading (`5.9%` of turns), and inline shell glue (`3.8%` of turns). Core dispatching/steering (`10.0%` of turns) and owner communication/decisions (`15.0%` of turns — over half of which are short status blurbs duplicating the panel) take **only `25.0%` of turns**.
- **Combined savings:** Zero-code config + delegation/workflow rules alone save **~52% (`~78M` Opus prompt tokens/day, `~$25/day` net)**. Full adoption of Ranks 1–8 (Integrator/Scout `sonic`, schema cleanup, batch/digest MCP tools, and panel-first status/actions) cuts Opus load by **~80% net (`~125M` Opus prompt tokens/day saved, bringing a full MyHUD day from `~$48.60/day` down to `~$8.60–$10.10/day` incl. `sonic` worker costs)** while preserving 100% test-before-land discipline.

### 3.2 MCP ↔ Panel & Tool Payload Findings
- **Chat duplicates the panel:** `110` of `781` turns (`23.98M` prompt tokens) are text-only replies (`99` of `175` text blocks are `≤240` chars), driven in part by `integrations/skills/hud-delegate/SKILL.md:14` asking `orch` to announce every job ID in chat.
- **MCP-Tasks blocks panel events (`src/mcp/thin-main.ts:1877`):** `withChanges` skips `tries.jsonl` and `panel-actions.jsonl` when `taskClient === true`, forcing `Monitor` (`7,591`-char schema = `1.69M` token-turns) or chat prompts for owner try/question actions.
- **Singular-only MCP mutations (`191` `hud_*` calls across `168` turns = `40.04M` turn prompt tokens):** `hud_create` (`60` calls, `106.6 KB` inline briefs), `hud_read` (`55` calls), `hud_tickets` (`33` calls, `17` one-by-one `update`s), and `hud_respond` (`18` calls) lack batch arrays; `sampleTask` (`thin-main.ts:2017`) wakes `orch` at `~459` tokens/notice **before** `hud-check.mjs` finishes.
